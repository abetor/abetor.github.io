rig - open-source coding-agent orchestration, personal project, 2026

rig evaluates coding-agent changes before a human decides whether to accept them. Each task runs in an isolated Git worktree. Reviewers inspect the staged diff; command gates and a schema-constrained judge check the changes before human acceptance. SQLite state supports recovery after interruption. The repository includes a runnable demo, tests in CI and an offline acceptance test that needs no model credentials. Used by two people, with repeated local runs. MIT license.
